AYOVANI System Architecture

SIH 2026 Team Project: Technical breakdown of the edge-first speech translation pipeline engineered for low-resource tribal language education.

1. Cross-Checked Data Engineering (Karya Corpus)

20,000 raw Hindi–Mundari parallel sentence pairs cleaned and deduplicated to 19,910 clean pairs; expanded to 39,820 bidirectional training examples using direction tags (hin_Deva ↔ mun_Deva) with tokenizer extension (mun_Deva ID 122706).

2. Single-Model Architecture & QUInt8 ONNX Quantization

Replaced dual unidirectional models (which hit 700 MB OOM) with a unified 320M IndicTrans2 engine. Dynamically quantized FP32 weights (1,224 MB) down to 115.99 MB QUInt8 ONNX, slashing active memory to 183–347 MB to clear the 400 MB RAM budget for 2 GB Android tablets.

3. Speech Pipeline & Latency SLA

STT powered by AI4Bharat IndicConformer (120M, INT8 ONNX, 2.37s CPU latency). TTS powered by fine-tuned Piper-VITS (18.4 MB INT8 ONNX, 0.08x Real-Time Factor). Concurrent clause-level streaming achieves 2.05s–2.45s Time-To-First-Audio with zero cloud dependency.
